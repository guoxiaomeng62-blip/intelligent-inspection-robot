# 常见硬件接口补充

本版补充common_devices.c/h，实际实现PWM/DIR电机驱动、方向反转停顿、PCA9685寄存器通信、HC-SR04触发与回波计时、16位编码器回绕测速。与control.c搭配使用，基于STM32F407 HAL。

## 统一接线

|设备|STM32接口|说明|
|---|---|---|
|左驱动PWM / DIR|PA8 TIM1_CH1 / PC0|PWM高电平有效，方向由DIR指定|
|右驱动PWM / DIR|PA9 TIM1_CH2 / PC1|两侧极性按架空测试修正|
|双驱动使能|PC2|高有效；外部下拉，上电禁用|
|左右编码器AB|PA6/PA7 TIM3、PB6/PB7 TIM4|编码器模式；输入需兼容3.3V|
|PCA9685 SDA/SCL|PB9/PB8 I2C1|地址0x40，逻辑电源3.3V，上拉至3.3V|
|PCA9685 OE|PC3|高电平禁用，外部上拉；初始化期间保持禁用|
|六路伺服信号|PCA9685 CH0~5|腰、肩、肘、腕俯仰、腕旋转、夹爪|
|前后左右超声Trig|PD0~PD3|逐个触发，每次间隔至少60ms|
|前后左右超声Echo|PD4~PD7 EXTI4~7|双边沿中断；5V Echo必须分压或电平转换|
|急停状态|PC4|外部上拉，常闭回路接地；断线或按下均读高并停车|
|驱动故障|PC5|外部上拉，常闭健康回路；驱动原始信号按手册隔离适配|
|机械臂收拢确认|PC6|实际位置/限位反馈，不能按动作时间模拟|
|BMS通信|PB10/PB11 USART3|本版不再用于总线伺服；BMS具体帧格式须选定型号后实现|

TIM1设置20kHz PWM；TIM5设置1MHz、ARR=0xffffffff。TIM3/4全周期编码器模式。若定时器时钟不同，重新计算分频，不能直接复制预分频数值。检查具体开发板资源冲突。

## 电机驱动与伺服选择口径

采用通用工业24V PWM/DIR/EN接口直流驱动器，两路独立。此处选择的是电气接口而非指定某块驱动板；驱动额定/峰值电流必须与实际电机匹配，并核实3.3V输入兼容性。禁止将PWM/DIR输出接入不支持该模式的驱动器。

机械臂采用接受50Hz、1000~2000us信号的带减速机构位置伺服执行器。PCA9685只产生信号，不能为六个关节供电，执行器由独立电源供电并共地。不是所有工业伺服都支持这种接口；购买前须核对。16kg机械臂每个关节的力矩和制动保持能力必须校核，不能用MG996R等小型舵机替代。PCA9685没有位置和力矩反馈，需另接关节位置检测或收拢限位。

## 主循环接入顺序

初始化GPIO安全电平→PWM占空比清零→启动TIM1 PWM、TIM3/4编码器及TIM5→PCA9685初始化→control_init。失败时禁止使能。初始化后按10ms调用control_step，每60ms轮询一个超声波；Echo双边沿中断调用sonar_edge，时间戳来自TIM5及HAL_GetTick。一次只允许一个超声模块发射，避免串扰。

board_motor将左右输出交给motor_write；方向翻转固定等待100ms只是调试参数，实机还须确认编码器停稳并按驱动手册延时。board_safe_stop清PWM和PC2，不应切断承载中的机械臂电源导致自由落下。

board_sensors通过encoder_mps计算速度，metres_per_count=驱动轮有效周长/输出轴每圈计数；如果是电机轴编码器，还需除减速比。四路sonar_read全部成功后取最小净空；任一路丢失或过期置valid=false。超声波只是调试级接口，不能替代工业安全传感器。

board_arm_start必须调用已标定的多关节轨迹，通过pca_servo逐步发送六路脉宽，并利用真实位置反馈判断收拢。首次开机读取实际关节位置前禁止直接发送中位值；机械臂闭链约束与碰撞限制仍由轨迹实现，通用脉宽协议无法推断机械结构。

BMS未接入时battery_soc和valid不得填写常量假装正常。电池电压不能直接当作SOC。现有代码不会因本文件而自动具备导航、仪表识别或回充对接能力。
