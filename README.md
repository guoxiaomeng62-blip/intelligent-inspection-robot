# 智能巡检机器人核心控制代码

树莓派5负责巡检任务与视觉接入，STM32F407负责履带、编码器、传感器和机械臂接口。

## 目录

- firmware：STM32控制核心、通用设备驱动及集中参数。
- host：Python巡检状态机与串口发送接口。
- config：离线仿真反馈样例，不代表实测数据。
- docs：硬件配置、接线与集成步骤。

本仓库是开发用核心代码，不是完整可烧录工程。机械臂标定标记默认关闭。具体接入限制请阅读docs。

Python要求3.10或更新版本；串口依赖见requirements.txt。默认运行host/pi_link.py只发送停车指令。

固件需要STM32CubeF4 HAL和匹配的板卡工程，本仓库不附带第三方HAL库。
